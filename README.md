# MusicAI Studio

Estúdio web de criação musical com IA, reconstruído a partir das especificações recuperadas do projeto Emergent.

## Estado atual

- Interface dark/neon para produtores
- Estilos Trap, Pop, EDM e RnB
- Idiomas Português, Inglês e Espanhol
- Clima/mood e energia
- Geração simulada de letra e metadados musicais
- Separadores Letra/Cifras preparados
- Guardar música na biblioteca (estado local do protótipo)
- Área de stems com estado Em Breve
- Layout responsivo

## Desenvolvimento

```bash
npm install
npm run dev
```
